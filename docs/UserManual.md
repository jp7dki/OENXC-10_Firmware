# OENXC-10 ニキシー管時計 ユーザーマニュアル

本製品をご利用いただきありがとうございます。
このマニュアルでは、お手持ちのスマートフォンやパソコンを使って、時計をWi-Fiに接続する方法や、各種設定（時刻合わせ、表示モードの切り替えなど）を行う方法について解説します。専門的な知識がなくても設定できるようになっていますので、手順に沿って進めてください。

---

## 1. 時計へのアクセスとWi-Fiの初期設定（APモード）

購入直後やWi-Fi環境が変わった場合は、まず時計自体が発信しているWi-Fi電波（アクセスポイント）にスマートフォン等で接続し、設定画面を開く必要があります。

### 接続手順
1. 時計の電源を入れます。
2. スマートフォンやパソコンのWi-Fi設定画面を開きます。
3. 飛んでいるWi-Fiネットワーク一覧の中から、**`OENXC-10`** という名前（SSID）を探してタップします。
4. パスワードを求められた場合は、**`password`** と入力して接続します。
5. 接続が完了したら、スマートフォンのブラウザ（SafariやGoogle Chromeなど）を開き、アドレスバーに **`http://192.168.4.1`** と入力してアクセスします。
6. 設定画面（コントロール画面）が表示されます。

> [!NOTE]
> 設定画面内の「Wi-Fi Settings」項目から、ご自宅のWi-FiのID（SSID）とパスワードを入力して保存すると、時計がご自宅のWi-Fiルーターに接続されます。
> 時計がご自宅のWi-Fiに繋がった後は、スマートフォンをご自宅のWi-Fiに戻し、ルーターから時計に割り当てられたIPアドレスを入力することでも設定画面にアクセスできます。

---

## 2. 稼働状況の確認（Network & System Status）

設定画面の最初にあるパネルでは、現在の時計の状況がひと目でわかります。

- **Wi-Fi SSID:** 現在時計が接続しているご自宅などのWi-Fiネットワーク名が表示されます。
- **NTP Sync Status:** インターネット上の正確な時計（NTPサーバー）と時刻合わせができているかを表示します。
  - `Synced` と表示されていれば、現在時刻は正確です。
- **Last Sync:** 最後にインターネット経由で時刻をぴったり合わせた日時です。

---

## 3. 時刻の手動設定（Time Settings）

通常、インターネットに繋がっていれば自動で時刻が合いますが、インターネットがない環境で使う場合や、意図的に時刻をずらしたい場合は手動で設定が可能です。

- **スマートフォンの時刻を時計にコピーする**
  「Sync Time with this Device」というボタンを押すと、現在アクセスしているスマートフォンやPCの時刻がそのまま時計に送信され、瞬時に設定されます。これが最も簡単な方法です。
- **好きな日時を直接入力する**
  年、月、日、時、分、秒の各入力欄に数字を入力し、「Set Custom Time」を押すと、指定した日時に設定されます。

---

## 4. 表示モードの切り替え（Display Settings）

「Operation Mode（動作モード）」の項目から、以下の2つのモードを切り替えることができます。

### ① Clock Mode（通常時計モード）
通常の時計として動作するモードです。
- **毎時0分のエフェクト演出:** 毎時0分0秒になると、すべての桁が3秒間「シャッフル（数字がスロットマシンのようにランダムに切り替わる）」状態になります。その後、一番下の桁から順番にカシャッ、カシャッと止まり、新しい時刻の表示に確定するダイナミックな演出が行われます。

### ② Random Demo Mode（乱数デモ表示モード）
展示会やイベントなどで、時計としての表示を止め、数字をシャッフルする演出だけを見せたい場合に使用するモードです。

- **モードを切り替えた直後:** すべての桁が `000000` にリセットされ、時刻表示が停止します。
- **演出の発生方法:** 画面に新たに現れる「**Trigger Random Shuffle**」というボタンを押してください。
  1. ボタンを押した瞬間、すべての桁が高速でシャッフルを始めます。
  2. シャッフルは5秒間続きます。
  3. その後、一番下の桁から順番に数字が確定していきます。
  4. すべての桁が確定すると、ランダムに選ばれた数字（乱数）が表示されたままになります。
- もう一度ボタンを押すと、再びシャッフルが始まり、新しいランダムな数字が表示されます。

> [!TIP]
> 演出モードから通常の時計に戻したい場合は、Operation Mode を「Clock Mode」に戻してください。自動的に現在の時刻表示に復帰します。
