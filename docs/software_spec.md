# ESP32 デュアルコア FreeRTOS 設計ルール

## 1. コア割り当てと責務の分離
ESP-WROOM-32はデュアルコア構成です。タスク生成時は必ず `xTaskCreatePinnedToCore` を使用し、実行コアを明示してください。

- **Core 0 (PRO_CPU): 通信・プロトコル処理専用**
  - Wi-Fi、Bluetooth、MQTT、HTTP通信などのネットワークスタックを担当します。
  - 重い計算処理や長時間のブロッキング処理を直接実行してはいけません。
- **Core 1 (APP_CPU): アプリケーション・制御処理専用**
  - センサー値の取得、アクチュエータやモーター制御、UI・ディスプレイ描画を担当します。
  - ※通常のArduinoの `setup()` および `loop()` はデフォルトでCore 1上で動作します。

## 2. ウォッチドッグタイマ（TWDT）と無限ループの制約
タスク内の無限ループ（`for(;;)` や `while(1)`）は、必ずCPUリソースを譲渡（Yield）する処理を入れてください。

- **Core 0のタスク**:
  - ループ内には最低でも `vTaskDelay(pdMS_TO_TICKS(1))` を挟むか、Queueの受信待ちでブロック状態にしてください。Core 0のIDLEタスクが動作できなくなり、Task Watchdog Timer（TWDT）リセットが発生するのを防ぐためです。
- **ビジーウェイトの禁止**:
  - 長時間の `delayMicroseconds()` や空の `while` ループによる待機は禁止します。
- **高精度な周期的処理**:
  - 一定周期で正確にタスクを起床させる場合は、`vTaskDelay()` ではなく `vTaskDelayUntil()` を使用してください。

## 3. コア間データ連携と排他制御
コアをまたぐ変数の共有は、不具合の原因となるため厳格に管理します。

- **グローバル変数の生アクセス禁止**:
  - コア間で共有するグローバル変数を直接読み書きしてはいけません（`volatile` の付与だけではマルチコア間のキャッシュ不整合を防げません）。
- **データの受け渡し**:
  - コア間のデータ受け渡しには必ず `QueueHandle_t`（FreeRTOS Queue）を使用してください。
- **ハードウェアバス（I2C / SPI）の保護**:
  - 複数のタスクから同一のペリフェラル（`Wire` や `SPI`）を叩く場合は、必ず `SemaphoreHandle_t`（Mutex）で `xSemaphoreTake()` / `xSemaphoreGive()` を行い排他制御を実装してください。デッドロックを防ぐため、タイムアウト時間には適切な値を設定してください。
- **軽量なイベント通知**:
  - 単純な割り込み通知やイベントフラグには、タスク通知（`xTaskNotifyGive()` / `ulTaskNotifyTake()`）を利用してください。

## 4. タスク生成時の実装基準
- **関数シグネチャ**:
  - `void TaskFunctionName(void *pvParameters);` の形式で定義してください。
- **スタックサイズの設定**:
  - ※ESP-IDFのFreeRTOSは、スタックサイズを「ワード数」ではなく「バイト数」で指定します。
  - 単純なI/O・監視タスク: 2048〜3072 バイト
  - Wi-Fi/TLS暗号化/JSONパースを伴うタスク: 4096〜8192 バイト以上を確保してください。
- **優先度（Priority）の割り当て**:
  - 1（Idleの直上）〜 `configMAX_PRIORITIES - 1` の範囲で設定してください。
  - リアルタイム性の要求される通信・プロトコル処理: 3〜5
  - センサー取得・表示更新などの通常タスク: 1〜2

# WiFi接続機能詳細
WiFiにより以下の機能を実装します。
WiFi接続はクライアントモードとアクセスポイントモードを実装します。

## アクセスポイントモード
接続する相手先が見つからない場合、もしくは電源投入時はアクセスポイントモードになります。
- SSIDは "OENXC-10"、初期パスワードは"password"です。
- CaptivePortalを使い、設定画面を自動的に開くようにします。
- 設定画面では以下の設定を行えるようにします。
    - 接続しているクライアントとの時刻同期
    - クライアントモードとして接続するアクセスポイントの設定
        - SSID, パスワードの設定
        - クライアント接続時のIP設定（DHCPか固定IPか）
        - 接続するNTPサーバの設定
    - 累計点灯時刻の表示
    - 表示切り替えモードの設定
        - 通常の切り替え、フェード、クロスフェードを実装してください
    - ニキシー管電流の設定
    - 輝度調整の設定
        - 自動調整もしくは周囲の明るさに応じた自動調整
    - 節電モードの設定
        - 有効・無効化
        - 自動ON/OFF時間の設定

## クライアント接続モード
- NTPサーバに接続し、自動で正確な時刻同期を行います。
- クライアント接続中も同時にアクセスポイントモードでも動作するものとします。
